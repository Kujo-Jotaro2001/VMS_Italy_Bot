# VMS Italy — монитор слотов

## Установка (один раз)

```cmd
pip install -r requirements.txt
playwright install chromium
```

## Настройка

### 1. Telegram бот
1. Открой Telegram → найди @BotFather → `/newbot`
2. Придумай имя и username боту
3. Скопируй токен (вида `123456:ABC-DEF...`)
4. Вставь в `config.py` → `TELEGRAM_BOT_TOKEN`
5. Напиши своему боту любое сообщение
6. Запусти `python setup_telegram.py` → скопируй `chat_id` → вставь в `config.py`

### 2. Данные записи
В `config.py`:
- `BOOKING_NUMBER` — номер записи (например `011/2026/04/17/0018`)
- `PASSPORT_NUMBER` — номер загранпаспорта (только цифры)

## Запуск

```cmd
python bot.py
```

Первый раз запускай с `HEADLESS = False` (видимый браузер) чтобы убедиться
что бот правильно навигирует по сайту. Потом можно переключить в `True`.

## Что делает бот
- Заходит на сайт, вводит номер записи + паспорта
- Переходит на страницу переноса даты
- Каждые ~55 секунд кликает капчу когда она сбрасывается
- Если появляется свободный слот — нажимает кнопку переноса и шлёт уведомление в Telegram
- При разрыве сессии автоматически перелогинивается
